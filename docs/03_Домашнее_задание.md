# Домашнее задание — вебинар 1 «Что лежит в переменной»

Это продолжение того же проекта, а не новая работа. Всё, что нужно, уже лежит
в `practice/`: код, тесты и команда проверки. Студент получает стартовый ZIP
**без** `reference/` — каталога с готовыми ответами. После распаковки откройте
папку `practice/` в редакторе.

## Что сделать

**Обязательная часть — две вещи.**

1. Довести до зелёного три задачи эфира, если не успели на вебинаре:
   `task1values/`, `task2slices/`, `task3zero/`.
2. Решить домашний блок `homework/inventory.go` — три функции складского учёта.

```bash
cd practice  # из корня распакованного стартового архива

go test ./...            # все задачи и домашний блок сразу
go test ./homework       # только домашний блок
go run ./cmd/labcheck    # общий отчёт: что уже сходится, а что нет
```

Домашний блок — это `homework/inventory.go`, один файл и три функции:

| Функция | Что обязана делать |
|---------|--------------------|
| `Reserve(items []Item, sku string, qty int) bool` | уменьшить количество у первой позиции с артикулом `sku` на `qty` так, чтобы изменение увидела вызывающая сторона; при нехватке остатка или отсутствии артикула ничего не менять и вернуть `false` |
| `Snapshot(items []Item) []Item` | вернуть копию списка, живущую своей жизнью: правки копии не видны в оригинале и наоборот |
| `GroupBySKU(items []Item) map[string]int` | вернуть суммарное количество по каждому артикулу; в результат должно быть можно писать сразу, даже если вход пуст или `nil` |

Сигнатуры и тесты менять нельзя — они и есть условие задачи.
Для `Reserve` базовые тесты предполагают положительное `qty`; нулевое и
отрицательное количество не входят в проверяемую постановку.

**Подсказка:** каждая из трёх функций повторяет
ошибку одной из задач эфира. Найдите, какой именно, — и решение уже известно.
Комментарии `TODO(домашнее задание)` отмечают места, но задачу не называют:
узнать её помогает сообщение упавшего теста.

**Необязательная часть.** Если хочется большего — допишите свой тест, который
ловит одну из сегодняшних ошибок, и добавьте его в тот же пакет. Это не влияет
на приём работы: обязательная часть засчитывается сама по себе и целиком.

## Что сдать

Ссылку на репозиторий с вашим решением. Достаточно ветки с изменёнными файлами
задач — ни оформления, ни отчёта, ни описания не требуется.

## Какой объём ожидается

Четыре файла: три файла задач эфира и `homework/inventory.go`. Правок в каждой
функции — от одной до трёх строк. Если получается больше десяти строк на функцию, скорее
всего задача решается не тем способом: остановитесь и перечитайте сообщение теста.

## Дедлайн

До начала вебинара 2. Разбор домашнего задания там не планируется, но вопросы
по нему в чат — это нормально и полезно.

## Что считается достаточным результатом

Ровно одно:

```bash
$ go test ./...
ok  	gobasics/variables/homework
ok  	gobasics/variables/task1values
ok  	gobasics/variables/task2slices
ok  	gobasics/variables/task3zero
```

Если все четыре пакета зелёные — работа сделана. Ничего сверх этого не нужно.

## Если застряли

1. Перечитайте сообщение упавшего теста: в нём написано не только «не сошлось»,
   но и почему.
2. Откройте сам тест — он короткий и написан как объяснение.
3. Запустите `go run ./cmd/demo` и найдите блок про ту же ошибку.
4. Если всё ещё трудно, задайте вопрос преподавателю. Эталонное решение
   `reference/` будет доступно для разбора после дедлайна: в студенческом
   архиве его намеренно нет.
